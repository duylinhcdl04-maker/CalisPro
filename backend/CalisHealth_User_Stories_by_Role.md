# CalisHealth — User Stories by Role

> Bộ User Story được xây dựng trực tiếp từ **53 Use Case** của CalisHealth.  
> Các Use Case có nhiều actor được chuyển thành User Story tương ứng cho từng role có tham gia.

# 6. Core User Story Format

Các User Story trong tài liệu sử dụng format chuẩn:

> **As a [Role], I want to [Action], so that [Business Value].**

Ví dụ:

> **As a User, I want to receive real-time feedback while exercising so that I can immediately correct mistakes in my technique.**

Cấu trúc này giúp liên kết:

**Actor → Use Case → User Story → Acceptance Criteria → Functional Requirement**

# 8. Product Vision

Các User Story trên có thể được gom lại thành vòng lặp sản phẩm cốt lõi:

**Assess → Personalise → Train → Analyse → Feedback → Coach Review → Adjust Plan → Progress → Reassess**

Trong đó:

- **User**: thực hiện mục tiêu và quá trình tập luyện.
- **AI Coach**: phân tích từng rep, đưa feedback real-time và tạo recommendation.
- **Human Coach**: nhìn toàn bộ quá trình, đánh giá các vấn đề dài hạn và điều chỉnh chương trình.
- **Admin**: duy trì dữ liệu, rules, exercise knowledge base và vận hành hệ thống.

> **AI Coach nhìn từng rep. Human Coach nhìn cả hành trình.**
